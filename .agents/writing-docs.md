# Research Skill 用户文档

稳定 Research Skill 的用户文档位于 `docs/research/<skill-name>.md`，目录与 `skills/research/<skill-name>/` 镜像。`in-progress` 与 `deprecated` 不要求用户文档。

文档面向需要理解能力边界的人，不复制 `SKILL.md` 全文。重点说明这个 Skill 负责什么、何时进入、与相邻 Skill 如何分工、读取和产生哪些科研对象，以及什么状态表示它完成了当前职责。

稳定 Skill 新增、改名或改变职责时，同步更新对应文档。长流程、数据库细节、模板和低频执行规则继续由 Skill 正文及其 references 维护。

安装命令统一以 `.agents/install-block.md` 为准。
