# Literature and Novelty Verification

Reviewer 的文献核验目标是建立足以支撑当前评议判断的外部参照，不把每次手稿 Review 扩张成完整 Literature Research。

## Search frame

从稿件的科学实质拆分检索概念：

- Research Question；
- research object / population / system；
- central phenomenon / relationship；
- intervention / exposure；
- measurement；
- method operation；
- central Claim。

对每一项补充规范同义词、历史术语、上位 / 下位分类、常用缩写和相邻方法名称。作者创造的新名称不能替代既有术语检索。

作者 citations 只作为 seed。至少补一条独立于作者 reference list 的检索路径；找到 closest prior work 后，根据判断需要继续 backward / forward citation chasing。

## Disconfirming novelty search

当稿件声称 `first`、`novel`、`previously unknown`、方法首创、唯一机制或类似 priority claim 时，主动搜索最可能推翻该主张的工作，例如：

- 同一 Research Question 的更早研究；
- 不同术语描述的相同现象；
- 同一 method operation 的前驱或平行实现；
- 不同 population / system 中已建立但作者未讨论的证据；
- conference / preprint / registry / repository 中时间更早的可核验工作。

没有命中只能说明当前检索没有找到，不能证明不存在。

## Reading depth

### Field calibration

用于理解领域背景、主流术语与主要路线。可以依赖高质量 review、metadata、abstract、代表性论文 Introduction / Discussion 或官方 guideline。该深度不能单独承担强“not novel”判断。

### Targeted verification

用于比较某个具体 prior work 与当前稿件。至少检查与判断直接相关的 Methods、Results、Figure / Table、Discussion，必要时检查 Supplement。

### Deep original-content verification

当某篇 prior work 可能改变 central judgment 时使用。必须取得足够原始内容独立回答：研究问题是否相同、方法是否实质相同、关键结果是什么、作者 Claim 到什么层级、population / system / measurement / analysis 有何边界。

以下判断必须达到 targeted verification 或 deep original-content verification，不能只靠 abstract / review 二手概括：

- “别人已经做过”；
- “方法本质相同”；
- “central Claim 已被证明 / 反驳”；
- “主要创新只是增量”；
- “prior evidence 与当前稿件直接冲突”；
- “已知方法局限构成 Major Concern”。

## Contribution map

不打分，按实际适用维度比较：

- Research Question contribution；
- population / system contribution；
- method contribution；
- evidence-level advance；
- mechanism contribution；
- boundary / generalization contribution；
- replication / validation contribution；
- contradiction resolution；
- application contribution。

一个工作可以在某些维度已有先例、另一些维度真实新增。Reviewer 应说明真实新增发生在哪里，而不是用单一“novel / not novel”标签压平。

## Bounded conclusion

如果没有找到直接先例，至少说明当前判断的检索边界：使用过的主要数据库 / 来源、核心检索概念、检索日期、必要的语言或时间限制，以及是否检查了最近邻工作的 citation network。

推荐表达是“在当前检索边界内未发现直接先例”，而不是“这是首次”。
