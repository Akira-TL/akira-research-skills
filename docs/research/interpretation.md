# interpretation

`interpretation` 把 Analysis Observation、Design、Study、Hypothesis 和 Literature 综合成证据边界内最窄的项目 Claim。

它特别约束状态与过程、关联与因果、内部一致性与独立重复验证等容易被语言放大的推断层级。统计显著性不能自动升级为过程、机制或因果结论；同一 Dataset、cohort 或 Study 中的不同材料也不自动构成独立重复验证。

长期人类 Interpretation 固定写入 `interpretation/<slug>.md`，目录索引为 `interpretation/README.md`。正文使用固定 H1/H2 与 Navigation，把 `Supported`、`Indirectly Supported`、`Qualified`、`Contradicted`、`Unresolved` 明确分开，并至少链接 `RESEARCH.md` 和一个真实上游人类科研 artifact。目录索引固定包含 `Objects` 与 `Relations`，后者至少复现每个 Interpretation 的真实上游人类关系，并可继续增加后续 Communication 或新 Research Question 的反向入口。
