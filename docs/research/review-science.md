# review-science

`review-science` 是 Review series 的核心科学有效性评议 Skill。它从 Reviewer 视角重建 `Claim → Evidence / Experiment / Analysis → assumptions → alternative explanation → supported inference`，判断当前材料真实能够支持到什么 inference level。

## 主要检查

根据当前 Claim 实际需要检查 Design、sampling、comparison、measurement、Analysis、uncertainty、robustness、causal / mechanistic boundary、external validity、scope 与 reproducibility。它不按固定 checklist 数量制造问题；只有会改变 Claim truth、scope、uncertainty 或主要 interpretation 的缺口才升级为实质 Concern。

## Concern

实质 Concern 至少明确 target Claim / section、evidence locator、Reviewer assessment、为什么重要、scientific consequence、Major / Minor severity、confidence 与 resolution criterion。

对 Major Concern，Reviewer 必须区分：

- 当前 Claim 成立所需的 minimum honest remedy；
- 只有保留更强 Claim 时才需要的 optional stronger evidence；
- 当前材料不存在诚实补救时需要撤回、降级或重新研究的 Claim。

核心原则是：**严在 Claim，克制在 Scope**。Review 的职责是判断当前证据边界，不是默认把论文扩成更大的研究项目。
